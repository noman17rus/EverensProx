# EverensProx 0.9.6 — WARP

Этот выпуск добавляет WARP как отдельный маршрут для каждого пользователя.

## Что нового

- **Переключатель WARP** в блоке «Маршрут» на главном экране.
- **Индикатор «WARP работает»** — проверяется фактический выход через
  Cloudflare, а не только положение переключателя.
- **WARP на сервере**: ключи WARP не попадают на телефон. Приложение получает
  только отдельный прокси `WARP` в подписке.
- **Только для своего профиля**: включение WARP одним пользователем не меняет
  маршруты остальных. VLESS/WDTT продолжают работать как раньше.
- **Без лимитов**: нет ограничений трафика, срока или числа устройств.
- **Понятный статус**: зелёный «WARP работает», красный «WARP не работает»,
  нейтральный «Проверяем WARP…».

## Как включить

1. Установите APK поверх 0.9.5 — данные и профили сохраняются.
2. Откройте «Доступ» → меню профиля → «Синхронизация».
3. На главном экране включите **WARP** в блоке «Маршрут».
4. Нажмите **«Подключиться»**.
5. Дождитесь зелёного индикатора **«WARP работает»**.

Переключатель появляется только после синхронизации профиля, когда сервер
отдаёт WARP в подписке. Старые версии приложения не показывают WARP, но
продолжают работать без изменений.

## Ограничения

- WARP-аккаунт общий: пользователи WARP выходят через один WARP-IP и делят его
  пропускную способность. Это не лимит устройств и не ограничение тарифа.
- Если Cloudflare WARP недоступен, индикатор покажет «WARP не работает».
  Обычный VLESS-маршрут при этом остаётся доступен.
- WARP — дополнительный маршрут, а не замена VLESS/WDTT.

## Проверено

- Подписка с `X-EverensProx-Features: warp` содержит `VLESS` и `WARP`.
- WARP-клиент существует только в одном inbound и направляется правилом
  `user=warp@everensprox` в `warp-emergency`.
- Глобальный балансировщик не переключается, другие клиенты не затрагиваются.
- На устройстве: включение WARP → выход `104.28.232.200` (Cloudflare) →
  зелёный индикатор «WARP работает»; выключение убирает индикатор.
- Установка поверх 0.9.5 проходит без удаления данных.

## Установка

APK: `FlClash-0.9.6-android-arm64.apk`
(он же `FlClash-0.9.6-android-arm64-v8a.apk` для совместимости обновлений).

Контрольные суммы: `SHA256SUMS` и `FlClash-0.9.6-SHA256SUMS`.

Приложение проверяет обновления только в `noman17rus/EverensProx` и сверяет
SHA-256 APK по `SHA256SUMS`.
