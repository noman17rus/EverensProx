# Внешняя подписка домашнего сервера

Локальная панель управляет общим внешним выходом VLESS и WDTT через существующие
3x-ui, Xray и балансировщик `foreign-auto`. Поддержан каталог бесплатных резервных подписок с автоматическим переходом и возвратом. Клиентские UUID, порты, настройки WDTT и правила маршрутизации
при замене не меняются.

## Использование

Раздел **Пользователи WDTT** управляет всеми клиентскими доступами того же
сервера, что и Telegram-бот: поиск и фильтрация, создание личных и общих доступов,
изменение имени, VK-хеша, портов ссылки, пароля и срока, включение/отключение,
сброс привязки устройств и удаление. Карточка показывает ссылку подключения,
трафик за сегодня/неделю/месяц и всего, устройства и историю привязок.
Удаление и сброс привязок требуют подтверждения в интерфейсе.
Список обновляется автоматически; открытая форма сохраняет введённые значения.
Изменения выполняются через штатный admin-сокет работающего WDTT и сразу видны
боту. Сервер WDTT и Xray для этих операций перезапускать не требуется.

Настройки интеграции в `/etc/everensprox-subscription/config.json`:

- `wdtt_socket` — по умолчанию `/run/wdtt/admin.sock`;
- `wdtt_password_file` — закрытый файл с главным паролем WDTT, по умолчанию
  `/etc/everensprox-provisioning/wdtt-password`;
- `wdtt_public_host` — публичный адрес для ссылок (если не задан, берётся из WDTT);
- `wdtt_default_hash` — VK-хеш для новых пользователей; существующие хеши сохраняются.

Файл пароля должен быть доступен службе панели для чтения. Главный пароль и
профиль владельца не передаются браузеру. Все маршруты управления пользователями
используют существующую авторизацию панели, проверку LAN/Host/Origin и CSRF.
На сервере без настроенной интеграции остальная панель продолжает работать,
а раздел WDTT показывает ошибку подключения.

На текущем домашнем сервере откройте **http://192.168.1.239:19090** из домашней
сети. Пароль создан при установке и сохранён только в root-доступном
`/root/everensprox-subscription-backup-*/install-info.json` на сервере.

1. Войдите с паролем панели.
2. Вставьте HTTPS-ссылку подписки и нажмите **Проверить**. Если JSON содержит
   несколько профилей без «Автовыбора», выберите профиль и повторите проверку.
3. Дождитесь числа работающих узлов и нажмите **Применить**. Результат проверки
   действителен 15 минут. Соединения могут кратковременно прерваться.
4. При необходимости нажмите **Вернуть предыдущую**. Недоступную предыдущую
   подписку панель не применяет и объясняет причину.

В разделе **Выбрать подключение** показаны узлы активной подписки и текущий
используемый узел. **Проверить задержку** проверяет один узел, **Проверить все** —
весь список. Значение в миллисекундах — время до первого ответа HTTPS через
туннель с домашнего сервера, включая установку соединения; это не ICMP-пинг и не
измерение скорости скачивания. Проверки не меняют рабочее подключение.

Кнопка **Выбрать** сначала проверяет узел, затем закрепляет его для общего
внешнего выхода VLESS и WDTT. Новые соединения используют выбранный узел;
существующие соединения могут продолжать работать через предыдущий до своего
завершения. При отказе закреплённого узла проверяются остальные основные серверы, затем бесплатный резерв.
Кнопка **Автоматически** снимает закрепление и возвращает штатный `leastPing`.

Выбор хранится в `selection.json` и восстанавливается после перезапуска панели
или Xray (проверка каждые 5 секунд). Узел сопоставляется по настройкам подключения,
а не по позиции в списке: переименование не меняет выбор. Если узел исчез при
внешнем изменении конфигурации Xray, включается автоматический режим.
При штатном автообновлении исчезнувший
закреплённый узел сохраняет прежнюю конфигурацию до отмены ручного выбора.
Список и результаты измерений не содержат UUID, ключей и ссылок VLESS.

## Бесплатный резерв

Основная пользовательская подписка всегда имеет приоритет. Включите
**Автоматический бесплатный резерв**, чтобы при отказе всех основных серверов
панель переключала общий выход на проверенный бесплатный источник.

Начальный каталог: Parsabrg/free_sub, VLESS Collector (mehrtat), Alirewa,
igareck и Nodes Radar. Подписки принадлежат независимым публичным проектам;
доступность конкретных узлов зависит от домашнего провайдера. Для каждой ленты
берутся только поддерживаемые VLESS с TLS/Reality, остальные записи пропускаются.
Основной импорт сохраняет строгую проверку без потери параметров.

В панели можно добавлять, редактировать, включать, отключать и удалять источники
(до 32). Пустая ссылка при редактировании сохраняет прежнюю. Нельзя удалить,
отключить или изменить URL действующего резервного выхода: сначала переключите его.
Проверка серверов и загрузка подписки не включают этот источник автоматически.
Фильтр **Источник серверов** позволяет работать с одной подпиской; **Проверить все**
проверяет узлы выбранного фильтра. В карточке источника доступны обновление,
проверка его серверов и переход к списку.

Включённые бесплатные подписки обновляются каждые **12 часов после завершения
предыдущей попытки**, включая неудачную. Следующий срок сохраняется между
перезапусками. Ручное обновление доступно и для отключённого источника;
**Обновить все бесплатные** обновляет включённые. Основная подписка сохраняет
прежний часовой интервал. Ошибка ленты сохраняет её последний проверенный кэш.

Бесплатные ленты загружаются и проверяются фоновым рабочим потоком, отдельно
от блокировки операций панели. Одновременно обрабатывается одна лента; не более
четырёх туннельных проверок выполняются параллельно. Максимум 2 МиБ на ленту,
128 сохранённых узлов каждого источника. Большая лента проверяется группами по
128 до первой группы, содержащей работающий узел. Дубликаты внутри источника
схлопываются по параметрам подключения; одинаковые узлы разных источников
сохраняют принадлежность своим подпискам и не смешиваются в рабочем выходе.
Узлы с непубличными адресами пропускаются.

Рабочий выход проверяется HTTPS-запросом каждые 60 секунд после предыдущей
проверки. Если он отказал, проверяются все основные узлы. Две полные проверки
без рабочих основных серверов с интервалом не менее 60 секунд разрешают резерв.
Ошибки API, конфигурации и загрузки не считаются отказом серверов.
Резервные источники перебираются в порядке каталога; внутри выбранного источника
сохраняется штатный leastPing. Перед переходом основная проверяется повторно.

Ручной основной узел используется, пока работает. При его отказе закрепление
снимается, если доступен другой основной узел. Бесплатный сервер можно проверять
всегда, а выбрать — только при подтверждённом отказе всей основной подписки.
На резерве две успешные проверки основной с интервалом 60 секунд возвращают её,
**даже если бесплатный сервер выбран вручную**. При отказе резервного узла
используются другие узлы его подписки, затем другие включённые источники.

Выключение автоматического резерва запрещает новые автоматические переходы с
основной на бесплатную подписку. Уже действующий резерв сохраняется, а возврат
на восстановленную основную продолжает работать. Если рабочих вариантов нет,
конфигурация сохраняется и панель показывает причину.

`sources.json` хранит каталог, расписания, настройку резерва и кэши;
`active.json` — реально применённый выход; `selection.json` — ручной выбор.
Прежний единственный резерв автоматически переносится в каталог с ID `free`.
Миграция сохраняет основную подписку, действующий выход и историю ручных замен.
Журнал транзакции восстанавливает кэши, источник и закрепление. Результаты
фоновой проверки удалённого или изменённого источника не применяются.

Поддержаны обычные и Base64-списки `vless://`, конфигурация Xray и массив профилей
Happ. До 128 узлов, до 2 МиБ; TCP, WS, gRPC, XHTTP с TLS или Reality. Неизвестные
параметры отклоняются. Для JSON разрешены только узлы, представимые без потери
существенных транспортных настроек в формате ссылок VLESS; правила провайдера
не импортируются. Несовместимые возможности требуют обновления Xray или
адаптера, а не отключения проверки сертификатов.

Подписка загружается напрямую с сервера, независимо от текущего внешнего выхода.
Если адрес нового провайдера сам недоступен из домашнего подключения, проверка
сообщит об ошибке; обход блокировки адреса подписки отдельно не реализован.

Проверяется TLS/HTTPS-соединение через каждый узел в отдельном временном Xray,
максимум четыре процесса одновременно. Для применения достаточно одного узла.
HTTP 401/403 считаются ответом сервиса через туннель, но не гарантией доступа к
учётной записи или доступности всех сайтов. После применения проверяется также
действующий локальный SOCKS-вход либо, при его отсутствии, существующий
loopback-вход VLESS и маршрутизируемый через `foreign-auto` HTTPS-трафик.

## Установка и устройство

Нужны Linux/systemd, Python 3.10+, curl, существующие 3x-ui и Xray. Для проверки
через локальный Reality-вход без SOCKS также нужен OpenSSL. Этот установщик
предназначен для **имеющейся домашней установки**: адаптер
`pixelartick-subscription`, его конфигурация и кэш, локальная исходящая подписка
`http://127.0.0.1:19087/subscription`, префикс `pixel-`, балансировщик
`foreign-auto` с `fallbackTag=block`, входы VLESS/WDTT и локальный SOCKS для проверки.
Первичная авторизация берётся из существующего мониторинга. Для дальнейшей
работы создаётся отдельный API-токен `everensprox-subscription` с правами admin.
Версия API проверяется по доступности методов и фактической схеме конфигурации.

Передайте каталог на сервер, затем:

```sh
sudo python3 subscription-manager/install.py \
  --address 192.168.1.239 --subnet 192.168.1.0/24
```

Установщик проверяет API, текущую маршрутизацию и Xray, создаёт локальную резервную
копию, переносит кэш, останавливает старый адаптер и поднимает новую службу на
том же loopback-порту. Шаблон Xray и настройки клиентских входов не записываются.
При ошибке переключения исходный адаптер запускается обратно. Повторный запуск
установщика поверх существующего состояния запрещён.

Страница слушает только заданный LAN-адрес, проверяет подсеть клиента, Host и
Origin. Включены пароль PBKDF2, ограничение попыток, сессии HttpOnly/SameSite,
CSRF и CSP. Интерфейс использует HTTP внутри доверенной домашней сети; не
пробрасывайте порт наружу и не используйте его в недоверенной Wi-Fi-сети.
Веб-панель не заменяет сетевой экран; при активном firewall разрешите выбранный
TCP-порт только для домашней подсети. Закрепите LAN-адрес сервера в DHCP роутера.

Файлы службы:

- `/opt/everensprox-subscription` — код;
- `/etc/everensprox-subscription` — конфигурация, хэш пароля и отдельный API-токен;
- `/var/lib/everensprox-subscription` — активная, предыдущая подписки и журнал
  незавершённой операции. Каталоги закрыты, файлы состояния имеют права `0600`.

Loopback-источник отдаёт только сохранённый активный кэш и продолжает отвечать при отказе
провайдера. Основная подписка обновляется каждый час, бесплатные — каждые 12 часов с проверкой и откатом. Фоновая загрузка не мешает ручному управлению; применение результатов сериализовано с остальными изменениями. Изменения 3x-ui
между проверкой и применением требуют повторной проверки. Не редактируйте
исходящую подписку одновременно в обеих панелях.

Применение записывает журнал до замены активного файла. При ошибке восстанавливает
старый кэш и обновляет его в 3x-ui; при невозможности подтверждения оставляет журнал
и повторяет восстановление. После аварийного перезапуска журнал обрабатывается
автоматически. Недоступность старого провайдера отображается отдельно от ошибки
восстановления конфигурации.

## Проверка и обслуживание

```sh
python3 -m unittest discover -s subscription-manager -v
node subscription-manager/test_panel.cjs
sudo systemctl status everensprox-subscription
sudo journalctl -u everensprox-subscription --since today
curl --fail http://127.0.0.1:19087/health
```

Для обновления кода остановите **только** `everensprox-subscription`, замените
`server.py`, `backend.py`, `formats.py`, `index.html`, `password.py`, `wdtt.py` в `/opt/everensprox-subscription`
согласованным комплектом и запустите службу. Сохраните `/etc` и `/var/lib`, не
запускайте bootstrap-установщик повторно. Перезапуск панели не останавливает Xray.

Для смены пароля локально на сервере:

```sh
sudo python3 /opt/everensprox-subscription/password.py
sudo systemctl restart everensprox-subscription
```

Скрипт спрашивает новый пароль скрытым вводом. Перезапуск завершает все сессии.

Аварийное возвращение к старому адаптеру:

```sh
sudo systemctl disable --now everensprox-subscription
sudo systemctl enable --now pixelartick-subscription
```

Старая конфигурация адаптера сохранена отдельно; этот путь возвращает исходный
источник провайдера, а не последнюю замену из новой панели. Для восстановления
самой панели сохраните каталоги `/etc/everensprox-subscription`,
`/var/lib/everensprox-subscription` и root-резервную копию. Они содержат секреты;
не помещайте их в Git и не публикуйте.

## Проверенное обновление существующей установки

`verify_sources.py` запускается из закрытого staging-каталога на домашнем сервере.
Он проверяет бесплатные ленты через отдельные временные Xray, использует временный
loopback-источник и сохраняет кэши в `verified-state/`. Рабочая конфигурация не
переключается. `verification-progress.json` содержит результаты без ключей узлов.

После успешных тестов и проверки выполните из того же каталога `python3 update.py`.
Скрипт откажется обновлять изменившуюся после проверки установку или работать без
проверенного резерва. Он сохраняет код, конфигурацию и состояние в закрытую
`/root/everensprox-catalog-backup-*`, останавливает только службу панели, переносит
проверенные кэши и запускает обновлённую панель. Проверяет неизменность активной
подписки, ручного выбора, истории и конфигурации 3x-ui, затем действующий HTTPS-выход.
При ошибке восстанавливает предыдущий код и состояние. Сам Xray не перезапускается
скриптом обновления. Установщик `install.py` повторно не запускается.
