Бесплатный резерв

Основная подписка всегда имеет приоритет. Резерв включается после двух проверок без работающих основных узлов. После восстановления основной подписки выход возвращается на неё, в том числе после ручного выбора бесплатного сервера. Включённые бесплатные подписки обновляются каждые 12 часов.

Добавить бесплатную подписку

При редактировании оставьте ссылку пустой, чтобы сохранить прежнюю.

Выбрать подключение

Получаем состояние Xray…

Задержка — время ответа HTTPS через узел с домашнего сервера, не ICMP-пинг. Проверка не переключает подключение. Ручной выбор действует для общего внешнего выхода VLESS и WDTT.

Выбранный узел используется, пока доступен. При отказе сначала проверяются основные серверы, затем резерв. Бесплатный выход всегда уступает восстановленной основной подписке. Чтобы снять ручной выбор, нажмите «Автоматически».

Заменить подписку

Вставьте HTTPS-ссылку от нового провайдера. Проверка не меняет рабочие подключения.

VLESS-список, Base64, JSON Xray или Happ. Ссылка хранится только на сервере.

Проверка нескольких узлов может занять несколько минут. При применении соединения могут кратко прерваться.

Восстановление

Вернуть подписку, которая была сохранена перед последней заменой. Сначала проверим её доступность.
